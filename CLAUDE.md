# Prentice1 — prentice1.com

The marketing site for Prentice1, an aesthetic injector training and placement
program in Los Angeles. Static HTML, CSS and vanilla JS served from this repo
as-is (`CNAME` → prentice1.com). There is no build step, no bundler and no
package manager: what is committed is what ships.

This file is shared by every machine and macOS user that works on the repo, so
project-wide instructions belong here, not in anyone's `~/.claude`.

## Layout

- One directory per page, each an `index.html`: `/about`, `/apply`,
  `/practices`, `/sponsors`, `/privacy`, `/terms`, `/refund`,
  `/accessibility`. The homepage is `index.html`; `404.html` sits at the root.
- `assets/css/site.css` — the one stylesheet. Design tokens live on `:root`.
- `assets/js/site.js` — shared behaviour (reveal, motion gate, nav, GA4).
- `assets/js/apply.js` — the `/apply` form. Posts to
  `https://app.prentice1.com/api/applications` (`/api/`, never `/v1/`), with a
  `mailto:` fallback when the endpoint is unreachable.
- `assets/fonts/` — self-hosted WOFF2s; `fonts.css` declares them.
- `assets/video/`, `assets/img/` — every clip ships as both `.webm` and `.mp4`
  with a matching `*-poster.jpg`.
- `assets/og/` — share images, generated by `tools/make-og-images.py`.
- `docs/` — decisions and source material, not published pages.

Asset and page links are root-absolute (`/assets/...`), so preview from a
server at the repo root rather than opening files directly.

## Running it

```sh
python3 -m http.server 8000      # then open http://localhost:8000
python3 tools/make-og-images.py  # needs Pillow; rerun when a hero eyebrow or headline changes
```

## Rules that are easy to break

- **Brand Book Rev 2.0 (Oct 2026) is the authority.** Where the brand book,
  the redesign README and the `.dc.html` reference files disagree, the brand
  book wins. Any deliberate departure is recorded in `docs/brand-exceptions.md`
  with who decided it; add an entry there in the same change, or don't depart.
- **Colour and type come from the tokens** in `site.css`. Gold text on cream is
  `--gold-deep`, never `--gold` (2.1:1). Gilda Display (`--numeral`) is for
  figures 26px and up, never words.
- **Motion (§07):** one curve, `cubic-bezier(0.22, 0.7, 0.2, 1)`, under 600ms,
  nothing bounces or slides in from an edge, and `prefers-reduced-motion`
  collapses all of it. Content must never depend on motion: hidden states only
  apply under `.motion-ready`. The ambient hero drift is the one named
  exception (BX-02).
- **Dates come from `docs/cohort-1-calendar.md`.** Every published date is
  derived there from the two fixed anchors. Change the table first, then the
  pages, OG images and JSON-LD that repeat it.
- **Claims:** Prentice1 is a training program, not a certifying body. Never
  imply certification or licensure; scope of practice depends on licence and
  state.
- **`/apply` collects only C1/C2 fields** from the admissions contract. Never
  add licence numbers, date of birth, photo ID or street address to the static
  site; those belong to the platform Intake.
- **Stub pages** (`/terms`, `/refund`, `/accessibility`, `/about`, `404.html`)
  are `noindex,follow` and left out of `sitemap.xml`. Remove the noindex and
  add the page to the sitemap in the same change.
- **GA4** is wired but inert until `GA4_ID` in `site.js` is set.
- After editing copy, check the page's `<title>`, meta description, OG/Twitter
  tags and JSON-LD still agree with it.

## Conventions

- Plain vanilla JS in an IIFE with `"use strict"`, no dependencies.
- Comments explain *why* and cite the brand book section (§NN) or the decision
  they implement; match that density when editing nearby code.
- Commit subjects are a plain sentence describing the change, optionally with a
  short area prefix (`apply: ...`, `nav: ...`). No ticket numbers.
- Check every change at phone width and with reduced motion on.

## Working across devices

Use cloud sessions (claude.ai/code, or the Code tab in the Claude desktop and
iOS apps) signed in to the same Claude account, so a session started on one
device is visible on all of them. GitHub is the source of truth: commit and
push before switching devices, and pull on any local clone before starting.
